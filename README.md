Итоговый проект курса "Искусственный интеллект и ИИ-агенты в бизнесе 2026" от МФТИ. 
Проект представляет синтез списка повседневных задач (to do list) и тамагочи. 

Ссылка для ознакомления с сайтом: https://saferon1337.github.io/MFTI-course-project/

Проект создан с помощью нейросетей Deepseek и Claude с использование vite vue.js

У питомца есть 2 шкалы "Сытость" и "Счастье" с соответствующими статусами, которые постепенно снижаются (каждые 5 и 10 минут реального времени соответственно), а заполняются снова при выполнении заданий пользователем.
Задачи условно делятся на 2 типа "Полезные", повышающие в основном шкалу сытости, и "Весёлые", повышающие шкалу счастья питомца.

Некоторые задачи имеют дополнительное описание, которое генерируются отдельно с использованием сторонних API. 
Так, например, "Посмотреть фильм из топа" подтягивает при помощи стороннего API случайный фильм из топа 50 и его описание.
Аналогичным образом работает задача "Приготовить новый рецепт", которая подтягивает случайны рецепт по API с описанием блюда и списком ингредиентов.
также пользователь может создавать собственные задачи.

В текущем репозитории располагаются только исходники проекта (кроме папки node_modules)

Для запуска проекта на основе исходников установите Node.js (версия 18 или новее). Скачать можно с nodejs.org — выбирайте версию LTS.

Шаг 1 — Скачайте и сохраните исходник в любую удобную папку, например C:\Users\ВашеИмя\Desktop\pettasks.

Шаг 2 — Откройте папку проекта в терминале:
Откройте папку pettasks в проводнике, затем в адресной строке наберите cmd и нажмите Enter. 
В консоли пропишите команду "cd *ссылка на папку*" (например cd C:\Users\ВашеИмя\Desktop\pettasks)

Шаг 3 — Установите зависимости
В терминале выполните:
npm install
Это займёт меньше минуты — установятся все необходимые библиотеки.

Шаг 4 — Запустите приложение
Вариант А — режим разработки:
npm run dev
Откройте браузер и перейдите по адресу http://localhost:5173

Вариант Б — собрать и запустить финальную версию:
npm run build
npm run preview
Откройте браузер и перейдите по адресу http://localhost:4173
